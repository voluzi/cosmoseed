# Migrating to v0.12

v0.12 changes which addresses the seed announces. Only peers reached through an authenticated outbound connection are served through PEX and `/peers`, and the evidence expires after `verificationTTL` (30 minutes by default). Existing address-book entries remain dial candidates, but they do not become verified automatically. Expect an empty peer response immediately after startup while the seed reconnects and verifies candidates. Supply reachable `seeds` for a new deployment.

Configuration is read in this order: defaults, `config.yaml`, explicitly present environment variables, explicitly supplied flags. The effective result is validated and saved to the config file with mode `0600`; use `--config-read-only` when the file is mounted read-only. A present empty environment variable overrides YAML. Correct misspelled or retired fields before upgrading: YAML now rejects unknown keys. `addrBookStrict` is not a supported setting; use `allowNonRoutable` when private test networks require it. `chainID` is required; `seeds` may be empty after an address book has been populated.

`--show-node-id` is an identity-only operation: it can create and print the node key ID without `chainID`, and it does not persist the operational config.

For StatefulSets, provide `POD_NAME` and a comma-separated `EXTERNAL_ADDRESS` list with exactly one host:port per ordinal, or one scalar address for a single endpoint. IPv6 addresses must be bracketed. An invalid ordinal or an empty list entry now fails startup rather than advertising the wrong address. The Helm chart mounts read-only config and persists the node key and address book on a per-replica PVC. Set `config.externalAddresses` to reachable addresses before using the chart for public seeding; each configured address gets a separate pod-selecting P2P Service.

When using an external ConfigMap with the chart, set `existingConfigMapChecksum` and update it whenever the ConfigMap changes so the StatefulSet rolls its pods.

Existing `/peers` clients keep the comma-separated format. JSON is an array of verified peer metadata; TOML is a paste-ready `persistent_peers` assignment. `/readyz` now requires at least one fresh verified peer by default; set `minReadyPeers: 0` if startup readiness should not wait for discovery. Failed outbound dials are banned after `maxDialFailures` (default 5) for `banDuration` (default 1h), then retried without retaining verification. `/healthz`, `/status`, and a separate metrics listener are available for operators. The host default metrics address is `127.0.0.1:9090`; set `metricsAddr: ""` to disable it. The chart binds its metrics listener to `0.0.0.0:9090` and exposes it only through a separate metrics Service. Chart `version` is independent of `appVersion`; pin a released image tag for production deployment. Main builds publish `:edge` only; stable version tags publish the semver tag and `:latest`, while prereleases publish only their version tag.
